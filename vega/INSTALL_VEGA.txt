==============================================================
 FireTube Vega OS 版を Fire TV にインストールする方法
==============================================================

対象: Vega OS 搭載の Fire TV
      (Fire TV Stick 4K Select、Fire TV Stick 4K 第3世代 / HD の 2026年モデルなど)
      ※ Fire OS (Android) 搭載機は APK 版を使う -> ../INSTALL_FROM_PC.txt
      ※ Windows 11 PC から転送する場合は、最初から最後までの手順を
        TRANSFER_FROM_WINDOWS.txt にまとめています。


--------------------------------------------------------------
 最初に: Vega 版の状態と、インストールの仕組み
--------------------------------------------------------------
  - Vega 版は試作版 (vega-v0.1.0) です。GitHub Releases に .vpkg を置いています:
      https://github.com/iwa-kasoutuuuuuka/FireTube/releases  (タグ vega-v*)
    ビルドは GitHub Actions (Ubuntu + Vega SDK) で自動で行っています。
  - 実機での動作はまだ確認していません。特に動画の再生 (MSE / HLS) は
    端末によって動かない可能性があります。不具合はログと一緒に Issue へ。
  - Vega OS には APK のように「ファイルを入れればインストールできる」仕組みがありません。
    インストールできるのは次の 2 つだけです。
      (1) Amazon アプリストアで公開されたアプリ
      (2) 開発者モードにした端末へ、Vega CLI で入れたアプリ
  - FireTube はストア審査に通る見込みが低いため、(2) の方法で入れます。
    .vpkg をダウンロードすれば、自分でビルドする必要はありません。

以下は (2) の手順です。


--------------------------------------------------------------
 用意するもの
--------------------------------------------------------------
  - Vega OS 搭載の Fire TV (開発機と同じ LAN に接続)
  - USB データケーブル (Fire TV と開発機を最初に接続するため。充電専用ケーブルは不可)
  - Amazon 開発者アカウント (https://developer.amazon.com/ 無料)
  - 開発用 PC: Ubuntu 20.04 以上 または macOS 10.15 以上 (空き 20GB 以上)
      ※ Windows / WSL は公式に非対応。Windows PC しかない場合は Ubuntu の VM を作る
        (ステップ 1 の補足、または TRANSFER_FROM_WINDOWS.txt を参照)。
  - Node.js 18 以上、Python 3.8、lz4、Watchman (Vega SDK の前提)


--------------------------------------------------------------
 ステップ 1  開発用 PC に Vega SDK (Vega CLI) を入れる (初回のみ)
--------------------------------------------------------------
リポジトリを clone したフォルダで実行:
    bash vega/scripts/setup-dev-env.sh

最後に `vega --version` でバージョンが表示されれば OK。
新しいターミナルを開いたときは、最初に次を実行して vega コマンドを使えるようにする:
    source ~/vega/env

[補足] Windows PC しかない場合 (Hyper-V で Ubuntu 22.04 の VM を作る)
  管理者 PowerShell で実行:
    powershell -ExecutionPolicy Bypass -File E:\ZFireTube\vega\scripts\windows\create-ubuntu-vm.ps1
  Ubuntu のインストール時に「OpenSSH server」を選ぶ。完了後に ssh で VM に入り、
  リポジトリを clone してから上の setup-dev-env.sh を実行する。
  ※ VM から Fire TV への接続 (最初の USB 接続を含む) は、後述の
    「Windows 11 PC から実機に転送する場合」を参照。


--------------------------------------------------------------
 ステップ 2  Fire TV を開発者モードにする (初回のみ)
--------------------------------------------------------------
Fire TV 側:
  1. 設定 > マイ Fire TV > バージョン情報 で、端末名を選んで決定ボタンを 7 回押す。
  2. マイ Fire TV に「開発者向けオプション」が表示される。
  3. 開発者向けオプション > 開発者モード > 続行 で表示される 6 桁のコードを控える。

開発用 PC 側:
    vega devmode login                                # Amazon 開発者アカウントでログイン
    vega devmode enable-device --code <6桁コード>      # Fire TV が再起動する
    vega device list                                  # Fire TV が表示されれば OK

  ※ 開発者モードを有効にするたびに Fire TV の再起動が必要です。


--------------------------------------------------------------
 ステップ 3  .vpkg をダウンロードする
--------------------------------------------------------------
Releases の最新の vega-v* から、Fire TV Stick 実機用 (armv7) をダウンロードする:
    FireTube-Vega-<版>-armv7.vpkg       <- Fire TV Stick 実機用
    FireTube-Vega-<版>-x86_64.vpkg      <- Virtual Device (PC 上の仮想端末) 用 (あれば)

コマンドで取る場合 (例: vega-v0.1.0):
    curl -LO https://github.com/iwa-kasoutuuuuuka/FireTube/releases/download/vega-v0.1.0/FireTube-Vega-0.1.0-armv7.vpkg


--------------------------------------------------------------
 ステップ 4  Fire TV にインストールして起動する
--------------------------------------------------------------
    vega device install-app --packagePath FireTube-Vega-0.1.0-armv7.vpkg
    vega device launch-app --appName com.firetube.tv.vega.main

  - インストール後は Fire TV のアプリ一覧からも「FireTube」で起動できる。
  - 更新するときは、新しい .vpkg で install-app をもう一度実行する。

端末内を調べたいとき (不具合の報告用にログを見る):
    vega device shell


--------------------------------------------------------------
 Windows 11 PC から実機に転送する場合
--------------------------------------------------------------
Vega CLI と端末接続ツール VDA (adb に相当) は Windows 版がありません。
Windows 11 PC では Ubuntu の VM を経由して転送します。
(VM の作成から SDK の導入・インストールまで通しの詳しい手順: TRANSFER_FROM_WINDOWS.txt)

ポイント:
  - VDA は既定で USB 接続。Wi-Fi (TCP/IP) に切り替えられるが、最初の 1 回は USB 接続が必要。
  - Hyper-V の VM は USB を直接渡せないため、usbipd-win で USB をネットワーク越しに VM へ渡す。

[推奨] Hyper-V の Ubuntu VM + usbipd-win
  (VM はステップ 1 の補足 create-ubuntu-vm.ps1 で作ったものを使う)

  1. Fire TV Stick を USB データケーブルで PC に、HDMI でテレビにつなぐ。
     ※ 充電専用ケーブルは不可。PC の USB で電力が足りない場合は電源付き USB ハブを使う。

  2. Windows (管理者 PowerShell) で、Fire TV の USB を共有する:
       winget install usbipd
       usbipd list                          # Fire TV の BUSID (例: 2-3) を確認
       usbipd bind --busid <BUSID>

  3. Ubuntu VM で、共有された USB を接続して認識を確認する:
       sudo apt install linux-tools-generic hwdata
       sudo usbip attach -r <VM から見た Windows の IP> -b <BUSID>
       vega exec vda devices                # Fire TV が表示されれば OK
     ※ Windows の IP は VM で `ip route | grep default` の via の後ろ (Default Switch の場合)。
     ※ Windows ファイアウォールで TCP 3240 番 (usbipd) の受信を許可する必要がある場合がある。

  4. Wi-Fi 接続に切り替える (以降は USB ケーブルを抜いてよい):
       vega exec vda tcpip 5555
       vega exec vda connect <Fire TV の IP>:5555
       vega device list
     ※ Fire TV の IP: 設定 > マイ Fire TV > バージョン情報 > ネットワーク

  5. ステップ 4 と同じく install-app / launch-app でインストール・起動する。

[その他の方法]
  - VMware Workstation Pro (個人利用は無料) / VirtualBox の Ubuntu VM:
      USB を VM に直接渡せるので usbipd は不要。ただし Hyper-V と競合することがある。
  - Ubuntu を USB メモリから起動 (ライブ起動) / デュアルブート:
      公式の構成に最も近い。使うたびに PC の再起動が必要。
  - Mac を借りる: 一番簡単。

[未検証の点]
  - usbip 経由で VDA が Fire TV を認識するか。
  - Fire TV を再起動した後も Wi-Fi 接続 (tcpip モード) が続くか。
    adb では続かないため、再起動のたびに手順 2-4 (USB 接続) をやり直す可能性がある。


--------------------------------------------------------------
 使い方 (リモコン)
--------------------------------------------------------------
  ホーム        人気の動画の一覧。十字キーで選び、決定で再生。「検索」で検索画面へ
  検索          キーワードを入力して決定 → 結果から選んで再生
  再生中        決定 / 再生ボタン = 一時停止・再開
                左右 = 10 秒戻る・進む、早送り / 巻き戻し = 30 秒
                戻る = 一覧へ戻る
  - SponsorBlock の区間 (スポンサー・イントロ等) は自動でスキップする。
  - 画面下に「DASH 1080p / VISIONOS」のように再生経路が出る。不具合報告に添えてほしい。


--------------------------------------------------------------
 (開発者向け) 自分でビルドする場合
--------------------------------------------------------------
    cd vega/app
    npm install
    npm run build:app

できるファイル:
    build/armv7-release/*.vpkg                     <- Fire TV Stick 実機用
    build/x86_64-release/ , build/aarch64-release/ <- Virtual Device 用


--------------------------------------------------------------
 実機が無いとき (Virtual Device で試す)
--------------------------------------------------------------
Ubuntu の場合は KVM (/dev/kvm) が必要。VM の中では入れ子の仮想化が必要で、動くかは未検証。
    vega virtual-device start
    vega run-app <vpkg ファイル> <app-id> -d VirtualDevice
    vega virtual-device stop


--------------------------------------------------------------
 うまくいかないとき
--------------------------------------------------------------
■ vega: command not found
  - `source ~/vega/env` を実行していない。新しいターミナルごとに必要。

■ vega device list に Fire TV が出ない
  - 開発用 PC と Fire TV が同じネットワークにいるか確認 (ゲスト Wi-Fi は不可のことが多い)。
  - 開発者モードが有効か確認 (Fire TV の再起動後に無効になっていないか)。
  - 最初の 1 回は USB 接続が必要 (VDA の既定は USB)。Wi-Fi で使うには
    `vega exec vda tcpip 5555` -> `vega exec vda connect <IP>:5555` を先に行う。
  - VM から接続している場合は、外部スイッチ (ブリッジ接続) を試す。

■ 6 桁コードが通らない
  - コードには有効期限がある。Fire TV 側で開発者モードの画面を開き直して新しいコードを使う。
  - `vega devmode login` で、コードを表示したのと同じ Amazon 開発者アカウントにログインしているか確認。

■ install-app で失敗する
  - 実機には armv7 の .vpkg を使う (x86_64 / aarch64 は Virtual Device 用)。

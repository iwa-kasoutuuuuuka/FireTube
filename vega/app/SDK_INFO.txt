Available templates:

vegaWebview:	A webview template for Vega applications

Generate a new project from a template

Usage: vega project generate [options] [options]

Options:
  -t, --template     Template Id, run "vega project list-templates" to get the
                     list of valid values                    [string] [required]
  -n, --name         Project name. Alpha-numeric string with a max of 100
                     characters.                             [string] [required]
      --packageId    Package Id for manifest.toml, required in applications
                                                                        [string]
  -o, --outputDir    Output directory for template generation
                       [string] [default: "/home/runner/work/FireTube/FireTube"]
      --libraryName  Library name                                       [string]
      --idlPackage   IDL package name                                   [string]
      --uri          URI to load in the WebView
                             [string] [default: "file:///pkg/assets/index.html"]
  -h, -?, --help     Show help                                         [boolean]

Examples:
  vega project generate --template          Create a new application project
  helloWorld --name exampleProject          named exampleProject in the current
                                            directory
  vega project generate --template          Create a new Turbo Module project
  basicTurboModule --name MyTurbomodule     named MyTurbomodule in the /tmp
  --outputDir /tmp                          directory

$ vega device start-log-stream --help
Start streaming logs from a device

Usage: vega device start-log-stream [options]

Options:
  -d, --device    Serial number of a connected device. Defaults to the connected
                  device if there is only one.            [string] [default: ""]
  -h, -?, --help  Show help                                            [boolean]

Examples:
  vega device start-log-stream --device     Start streaming logs from device
  GXX2A1234567890A                          "GXX2A1234567890A"
[exit 0]

==============================================================
 FireTube を PC から Fire TV に転送してインストールする方法
==============================================================

対象: Fire OS 7 / 8 の Fire TV (Fire TV Stick HD / 4K / 4K Max / 4K Plus など)
非対象: Vega OS 搭載機 (Fire TV Stick 4K Select、2026年モデルなど)、Fire OS 6 以前
        -> APK をインストールできません。

用意するもの
  - Windows PC (Fire TV と同じ Wi-Fi / LAN に接続)
  - FireTube-v1.5.1.apk (GitHub Releases またはリポジトリ直下)


--------------------------------------------------------------
 ステップ 1  Fire TV 側の準備 (初回のみ)
--------------------------------------------------------------
1. 開発者オプションを表示する
   設定 > マイ Fire TV > バージョン情報 を開き、
   一番上の端末名 (「Fire TV Stick」など) で決定ボタンを 7 回押す。
   「開発者になりました」と表示されれば OK。
   (すでに「開発者オプション」がある場合は不要)

2. ADB デバッグをオンにする
   設定 > マイ Fire TV > 開発者オプション > ADB デバッグ = オン

3. Fire TV の IP アドレスを確認する
   設定 > マイ Fire TV > バージョン情報 > ネットワーク
   「IP アドレス」(例: 192.168.1.23) をメモする。


--------------------------------------------------------------
 ステップ 2  PC に ADB を入れる (初回のみ)
--------------------------------------------------------------
方法 A (おすすめ): PowerShell で次を実行
    winget install Google.PlatformTools

方法 B: 次の URL から「SDK Platform-Tools for Windows」の ZIP をダウンロードして展開
    https://developer.android.com/tools/releases/platform-tools
    展開したフォルダ (platform-tools) の中で PowerShell を開いて使う。
    (この場合はコマンドの adb を .\adb と書く)

確認:
    adb version
    -> バージョンが表示されれば OK。


--------------------------------------------------------------
 ステップ 3  接続してインストール
--------------------------------------------------------------
APK があるフォルダで PowerShell を開き、順に実行する。
(<IP> はステップ 1-3 でメモした IP アドレス)

1. 接続
    adb connect <IP>:5555

   初回はテレビ画面に「USB デバッグを許可しますか?」と表示されるので、
   「このコンピュータから常に許可する」にチェックを入れて「OK」を押す。
   ※ 許可したあとにもう一度 adb connect を実行する。

2. 接続を確認
    adb devices
    -> 「192.168.1.23:5555   device」と表示されれば OK。

3. インストール (上書き更新も同じコマンド)
    adb install -r FireTube-v1.5.1.apk
    -> 「Success」と表示されれば完了。

4. 起動
   Fire TV のホーム > アプリ一覧 (□が 3 つのアイコン) に「FireTube」が追加されている。
   PC から起動する場合:
    adb shell monkey -p com.firetube.tv 1

5. 切断 (任意)
    adb disconnect


--------------------------------------------------------------
 別の方法  ADB を使わず、PC から Downloader アプリで受け取る
--------------------------------------------------------------
PC に Python がある場合、PC を簡易 Web サーバーにして Fire TV から取得できる。

1. PC: APK があるフォルダで実行 (終わるまで開いたままにする)
    python -m http.server 8000
   ※ Windows ファイアウォールの確認が出たら「プライベート ネットワーク」を許可。

2. PC の IP アドレスを確認 (PowerShell で ipconfig -> 「IPv4 アドレス」)

3. Fire TV: アプリストアから「Downloader」をインストールする。
   設定 > マイ Fire TV > 開発者オプション > 不明ソースからのアプリ
   (機種によっては「アプリの提供元不明」) で Downloader をオンにする。

4. Downloader の URL 欄に入力して「Go」
    http://<PC の IP>:8000/FireTube-v1.5.1.apk
   ダウンロード後に表示されるインストール画面で「インストール」を押す。

5. 終わったら PC 側で Ctrl + C を押してサーバーを止める。


--------------------------------------------------------------
 うまくいかないとき
--------------------------------------------------------------
■ adb connect で「failed to connect」/ タイムアウト
  - PC と Fire TV が同じネットワークにいるか確認 (ゲスト Wi-Fi は不可のことが多い)
  - ADB デバッグがオンか確認。Fire TV を再起動してからもう一度試す。
  - IP アドレスが変わっていないか確認。

■ adb devices が「unauthorized」になる
  - テレビ画面の許可ダイアログを見落としている。
    adb kill-server -> adb connect <IP>:5555 で再表示させて「OK」を押す。

■ INSTALL_FAILED_UPDATE_INCOMPATIBLE (署名が一致しない)
  - 別の鍵で署名された旧版が入っている (v1.5.0 の GitHub Releases 版など)。
    一度アンインストールしてから入れ直す。視聴履歴などは消える。
    adb uninstall com.firetube.tv
    adb install FireTube-v1.5.1.apk

■ INSTALL_FAILED_OLDER_SDK / 「解析エラー」
  - Fire OS 6 以前の端末。FireTube は Fire OS 7 (Android 9) 以上が必要。

■ INSTALL_FAILED_INSUFFICIENT_STORAGE
  - 空き容量不足。使っていないアプリを削除するか、
    設定 > アプリケーション > インストール済みアプリケーションの管理 でキャッシュを消去する。

■ Downloader で接続できない
  - PC の http.server が動いているか、ファイアウォールで 8000 番が許可されているか確認。
  - URL のファイル名 (大文字小文字も) が実際のファイル名と一致しているか確認。


--------------------------------------------------------------
 アンインストール
--------------------------------------------------------------
  Fire TV: 設定 > アプリケーション > インストール済みアプリケーションの管理
           > FireTube > アンインストール
  PC から: adb uninstall com.firetube.tv
